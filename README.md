# Flight Operations & Performance Dashboard | Power BI

An interactive flight operations dashboard built using Microsoft Power BI to explore flight volumes, delays, cancellations, airline performance, and operational trends.

## Dashboard Preview

![Flight Operations Dashboard](https://github.com/hammadkazi16/Flight-Operations-Performance-Dashboard/raw/main/Screenshot%2026-11-01%130809.png)

## Project Overview

This project focuses on presenting flight operations data through an interactive dashboard, making it easier to monitor flight performance, analyse delays, understand cancellation patterns, and compare operational trends across cities and airlines.

## Key Features

- **Flight KPIs:** Total Flights, Delayed Flights, and Cancelled Flights.
- **Monthly Flight Analysis:** Visualizes total flight volumes and on-time performance trends by month.
- **City-wise Flight Analysis:** Compares flight volumes across different cities.
- **Airline Delay Analysis:** Examines delay percentages across different airlines.
- **Cancellation Analysis:** Breaks down cancelled flights by cancellation reason.
- **Weekly Cancellation Trends:** Analyses cancellation patterns across days of the week.
- **Flight Status Overview:** Provides a comparison of on-time, delayed, and cancelled flights.
